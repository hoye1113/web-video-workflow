# Warm emotion · grammar card（情感叙事）

参考：有知有行那类"讲得慢、记得住"的知识动画，以及本项目 26 页的基线成片（`projects/marriage_full`）。
**这份是风格宪法** —— 页面 agent 与评审 agent 都逐条读它。凡是"必须"，就是硬要求。

## 一句话

一个安静的旁观者，把一段关系里的**处境**摆给你看：暖色纸本的手绘插画，一页**只有一次有重量的动作**，
其余都停着；**光就是情绪**。

## 画面

- **主体是「处境」，不是图表。** 一页讲一个具体的人在具体的地方、做一件具体的事
  （孩子在书桌前写字、手机屏在昏暗房间里亮起、一个人坐在床沿背对镜头）。
  观众记住的是"那个画面里的处境"，不是"那个论点"。
- **角色只用 `小芽`（女）与 `小树`（男）**，必须由定妆图生成。
  **不许临时造脸、不许换衣服、不许摘掉头顶的嫩芽。**
  - `小芽`：暖粉齐肩微卷发 `#F6E4D8`、厚刘海、米白连帽衫 + 同色长裤、棕鞋 `#966C66`
  - `小树`：灰蓝短发 `#728A96`、浅灰蓝**开襟**外套 `#D2DEE4` + 白 T + 灰棕短裤 `#7C6867`
  - **两人头顶各有一株两片叶的小绿芽 `#DEF0A8`** —— 最强识别符号，**任何一页都不许丢**
- **先定光，再画东西。** 一页只有**一个主光源**，方向明确（窗在左 / 屏在脸前 / 顶灯在头顶）。
  亮部不必多，暗部要大。
- **一张生成图当底，代码只做三件事**：把图摆对位置、让它动、在上面加屏上字。
  **不要用代码重画图里的东西**（手、脸、有机形状尤其不许）。
- **屏上字只做标签**：每个元素 ≤ 8 个汉字，正文 ≥ 36px；数字写在物件上（写在本子上、写在屏幕上），
  **不许单独开数字卡**。
- **最下面 18% 一律留空**（字幕带）。任何屏上字、任何主体都不许进这条带。
- **同屏最多三个颜色在说话**，一眼只读一个信息。

## 运动与机位

- **一页一次有重量的动作。** 只让一件事发生：一只手把纸折起来、屏幕亮起、人低下头。其余全部静止。
  **不做整页匀速慢推。**
- **停 — 推 — 停**：动作前停一下，动作时**短推一次（约 0.3 秒）**落在主体上，然后停住让人看。
- **一张静图撑住 10–15 秒的五种手法**（每页**至少用两种**）：
  1. 慢推 / 横移（Ken Burns，幅度 3–8%）
  2. 分层视差（前中后景分开动）
  3. 明暗揭示（从暗到亮，或局部亮起）
  4. 细节插入（中段切进同场景的第二张图或特写）
  5. 文字依次出现（0.3 / 0.6 / 0.85 三个时刻分别出来）
- **元素入场 0.6–1.2 秒缓出**，落地要稳；**不弹跳、不闪烁**。
- 换页**少用硬切**，优先整页淡入淡出（像翻书）。

## 情绪与光

- **两套光**：日间（暖纸本、光从窗来）/ 夜间（深底暖光、单点光源）。夜间要**单独调组件**，不是换色值。

### 日夜怎么切（硬约定，写错就不生效）

```js
ENGINE.visual('p04', (P) => {
  STYLE.setTheme('night');     // ← 必须写在 visual 回调的**最前面**
  ...                          //    颜色是在"构建这一页"时烘焙进 DOM 的
});
```

- **换页要重新声明**：每页开头都写一次 `STYLE.setTheme('day' | 'night')`，别指望上一页的设置留到这一页
- **背景只在片级算一次**：所以夜间页要自己铺底 —— 用
  `P.light(..., { full: true, ground: 'paper' })`，那一下会把整页压成深底
- 整片都是夜间时，改 `script.js` 的 `META.look.palette` 更省事（引擎自带这条路）

### 情绪低谷靠调光，不靠换衣服

- 允许：整体降明度、暖色转冷、加暗角、压高光；把光从"窗口侧"改成"局部单光源"；
  表情在同一角色设定内变（低头 / 垂眼 / 抿嘴 / 背对镜头）
- **不允许：换外套、换下装、摘掉头顶嫩芽、改发型**
- 判据：和"日间版"并排看，要是**同一个人的不同处境**，不是"另一个角色的另一套衣服"

### 八个组件（`kit.js`，都在 `P.` 上）

| 组件 | 用途 | 关键参数 |
|---|---|---|
| `P.door(cx, baseY, w, h, o)` | 门框 + 门板 + 门缝的光 | `open` · `side` · `light` |
| `P.phone(cx, cy, w, o)` | 一块会亮的屏 | `lit` · `notify` · `tilt` |
| `P.photo(cx, cy, w, o)` | 相纸（内里只用色块，**不画脸**） | `tilt` · `lift` · `cut` |
| `P.silhouette(cx, baseY, h, o)` | **背景无名人物**剪影（⚠️ 不许拿它冒充小芽/小树） | `alpha` · `scale` |
| `P.paper(cx, cy, w, h, o)` | 一张纸：折 / 皱 / 撕 | `crease` · `crumple` · `tear` |
| `P.light(cx, cy, r, o)` | 光（**最重要的一样**） | `k` · `kind` · `full` · `ground` |
| `P.span(x0, x1, y, o)` | 实体长物（长桌沿/矮墙），用"同一张桌子两端很远"说距离 | `reach` · `thick` |
| `P.emptyseat(cx, baseY, w, o)` | 空出来的位置（椅子还在，人不在） | `fade` |

**凡是会变的属性都接受"数值或 `lt` 的函数"** —— 例如
`P.door(300, 900, 300, 500, { at: 0.3, open: (lt) => PV.clamp((lt - 1) / 3) })`。

## 节奏

- **10–15 秒一页**，页内每 **3–6 秒**有一个可见变化（**一页至少 4 个事件**）。
- 一页 = 一个完整的小论点 + 一段完整的话；**标题就是论点**。
- 结尾落在一个**动作**上，配一句朴素的口播；**不用居中金句卡收尾**。

## 绝不

- **图表 / 箭头 / 圆圈 / 流程图 / 时间轴 / 饼图** —— 一条都不许有。
- "标题 + 三张卡 + 箭头"的幻灯片排版。
- 屏幕塞满小字、表格、代码。
- 霓虹、发光渐变、蓝紫科技色、科技网格。
- 用代码重画照片级的东西（手、人脸、有机形状）。
- 屏上字落进最下面 18% 的字幕带。
- 主体太小（内容框 < 60%）或重心明显偏一侧。

## 评审逐条核（评审 agent 用）

1. **认得出是同一对角色** —— 发色 / 服装 / **头顶嫩芽** 都对得上吗？有没有换衣服、丢嫩芽？
2. **不违和** —— 角色和背景是不是同一支笔、同一套光？
3. **有处境感** —— 一眼能看懂"这人处在什么情境里"吗？还是"标题 + 图标"？
4. **没有图表味** —— 有没有箭头 / 圆圈 / 流程图 / 三卡？
5. **愿意发** —— 这一页单独拿出来，愿不愿意发出去？
