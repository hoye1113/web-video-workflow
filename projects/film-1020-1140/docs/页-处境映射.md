# 先道歉的人 · 页 → 处境映射表（13 页）

> **这张表定了，就照表出图。**
>
> 原则（`warm-emotion/GRAMMAR.md` + `docs/新题材开工手册.md`）：
> ① 主体是**处境**（谁 + 在哪 + 在做什么 + 光从哪来），不是图表；
> ② 一页**一次有重量的动作**（停 → 那一下 → 停），其余全停；
> ③ 屏上字只做**标签**（≤ 8 字），画面下方 18% 永远留空（字幕带）；
> ④ 角色只用 **小树**（男）/ **小芽**（女），靠 Flow 里**挂 chip** 锁形象 —— 提示词里不写名字、不写服装发型、不写嫩芽；头顶嫩芽 `#DEF0A8` 一页都不许少；
> ⑤ 生图**串行**，一次一张；失败不连坐，记原因继续；断点续跑。
>
> **读表约定**：「画面」列写的是**处境**（一个男孩/一个女孩 + 在哪 + 在做什么 + 光从哪来），
> 出图时照抄这一列当提示词主体；**角色身份看「主角」列**（挂 chip），不写进提示词。
> p13 是两人同框，主角写「小树+小芽」。

## 三处取舍（已按本表定，改动只需回一句）

**① p05 / p08 连着两页都是小芽**（一个攥纸、一个背对坐床沿）—— 保留。
　片子讲的是"先道歉的人"，但"被道歉的人"也要有脸；p06 紧跟着就是小树把责任全揽下去，对照才立得住。

**② p04 和 p11 都是"门口的手"**（男版 / 女版）—— 保留。
　一个"他先敲门"，一个"她忍住不说"，读起来是一组对照，不是重复。

**③ p13 要一张两人同框的图**，图库里没有，得新生成 —— 收在"并排坐着、手挨着手"。

## 施工顺序

```
1. 写 gen-queue.json（4 张新图，挂 chip，串行，每张约 60–100 秒）
2. 出图 → 逐张看图：发色/衣服/嫩芽对不上就挪到 experiments/rejects/ 重画
3. python tools/lib_index.py            → 刷图库索引
4. 填 asset：复用 9 张直接写图库文件名，新 4 张等出图后写
   → projects/film-1020-1140/page-spec.json（现在 asset 一律留空）
5. python tools/make_pages.py --project film-1020-1140
6. 配音 → 字幕 → 渲染 → 验收（tools/qc_snap.py + tools/accept_emotion.py）
```
