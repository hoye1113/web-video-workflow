# 分开之后，回避是希望你纠缠还是断联？· 页 → 处境映射表（26 页）

> **这张表定了，就照表出图。**
>
> 片子：说给**被回避的那一方**（伴侣视角）听 —— 「他推开我，是想让我追，还是想彻底断联」。
> 全片两个角色：**小树** = 回避的那个人（推开你的）；**小芽** = 等消息的那个人（你）。
>
> 原则（`warm-emotion/GRAMMAR.md` + `docs/新题材开工手册.md`）：
> ① 主体是**处境**（谁 + 在哪 + 在做什么 + 光从哪来），不是图表；
> ② 一页**一次有重量的动作**（停 → 那一下 → 停），其余全停；
> ③ 屏上字只做**标签**（≤ 8 字），画面下方 18% 永远留空（字幕带）；
> ④ 角色只用 **小树**（男）/ **小芽**（女），靠 Flow 里**挂 chip** 锁形象 —— 提示词里不写名字、不写服装发型、不写嫩芽；头顶嫩芽 `#DEF0A8` 一页都不许少；
> ④′ **提示词里别写"背对镜头"** —— 实测背对镜头会画掉头顶那株嫩芽（`sprout_px` ≈1）。要"不看对方"就写「侧身」「头转向另一边」；每张图都要量嫩芽像素，低于 ~50 重画；
> ⑤ 生图**串行**，一次一张；失败不连坐，记原因继续；断点续跑。
>
> **读表约定**：「画面」列写的是**处境**（一个男孩/一个女孩 + 在哪 + 在做什么 + 光从哪来），
> 出图时照抄这一列当提示词主体；**角色身份看「主角」列**（挂 chip），不写进提示词。

## 三处取舍（已按本表定，改动只需回一句）

**① 小树占 20 页，小芽只有 6 页（p01 / p03 / p08 / p19 / p22 / p25）。**
　　片子讲的是「回避的人心里在想什么」，所以主角是回避的那个人；
　　小芽出现的六页都是**你的视角**（等消息、不看手机、人空了、攥纸、抚平纸）—— 用来对位，不抢戏。

**② p12 / p23 / p26 连续三页都是"门"。**
　　保留：这三页正好是全片的转折（推开 → 绕开 → 门没关），门是这条线的母题。

**③ p06 / p20 / p21 复用的是 emotion-full 的图（尺子 / 剪刀 / 抽纸）。**
　　这三张图里没有手机、没有别人，处境是干净的，套到本片的主题上不冲突；
　　构图、留白带、嫩芽都过检，直接用，省三张的生成时间。

## 施工顺序

```
1. 写 gen-queue.json（5 张新图，挂 chip，串行，每张约 60–100 秒）
2. 出图 → 逐张看图：发色/衣服/嫩芽/留白带对不上就标 retry 重排
3. python tools/lib_index.py            → 刷图库索引
4. 填 asset：21 张复用直接写图库文件名，5 张新图等出图后写
   → projects/film-1020-1522/page-spec.json
5. python tools/make_pages.py --project film-1020-1522
6. 配音 → 字幕 → 渲染 → 验收（tools/qc_snap.py + tools/accept_emotion.py）
```
