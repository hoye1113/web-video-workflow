# 3:4 封面模板（2026-11-23 定稿）

> 后面所有封面都按这个排版做：**只换图和文案，排版不动**。

## 规格

- 尺寸：**1080×1440（3:4）**
- 底色：暗蓝 `#0b1220`
- 主色：暖黄 `#f1cf5e`
- 正文：米白 `#f5ead2` / 柔和米 `#c9b99a`
- 中文字体：微软雅黑粗体 / 常规（本地排版，不让 AI 写标题）

## 版式

```text
0     ┌────────────────────────────┐
      │ 李安老师 · <栏目>           │ 26px 暖黄
      │                            │
      │ 想离婚的人                  │ 126px 米白
      │ 先看看孩子                  │ 126px 暖黄
      │                            │
      │ 孩子要承受的，               │ 38px 柔和米
      │ 远比你想的多。               │ 38px 柔和米
      │ ────                        │ 黄色短线 140×4
600   ├────────────────────────────┤
      │                            │
      │      满宽场景图 1080×840    │ 从 y=600 一直到 1440
      │      左右铺满，不留边        │
      │      底部不留任何文字        │
1440  └────────────────────────────┘
```

## 规则

1. 顶部品牌行：**李安老师 · <栏目>**；栏目按当期内容改（婚姻与孩子 / 信任重建 / 等）。
2. 主标题两行：第一行米白，第二行暖黄；标题按内容改，字号自动缩到不超宽。
3. 副标题两行；没有副标题就留空。
4. 图片 **1080×840**，满宽、从 y=600 顶到画面底部；**绝不加底部文字**。
5. 图从当期成片原图里选一张，按 1080/840 的比例居中裁切；人物和道具可以按内容换，排版不动。
6. 图与标题之间只保留一条 2px 暖黄分隔线。

## 工具

```bash
python tools/cover_3x4.py 场景.png 输出.png \
  --brand "李安老师 · 婚姻与孩子" \
  --title1 "想离婚的人" --title2 "先看看孩子" \
  --sub1 "孩子要承受的，" --sub2 "远比你想的多。"
```

- 场景图建议用 `projects/scene-library/` 里的成片图（1920×1080 或更大）。
- 输出固定 1080×1440 PNG。
