# 12布布 · 成片流程

> 目前还没有正式片。等用户给音频后按下面的流程走。

## 输入

- 用户音频：`E:\音频素材\<片号>.mp4`（或 wav）
- 目标：只交 **无字幕 mp4**

## 步骤

1. **抽音频 + 转写**
   - `ffmpeg -vn -ar 48000 -ac 2`
   - `tools/transcribe.py` → JSON/SRT/TXT
   - 修正错字；必要时繁转简

2. **分页**
   - `tools/new_film.py <片名> --title ... --minutes ...`
   - `tools/audio_film.py <片名> <fixed.json> <audio.wav> --page-chars 37 --page-sec 6.0 --max-cue 20`
   - 检查页数、cue、字数；页长不要过短或过长

3. **写页面 prompt**
   - 每页按 `prompts/base.md` 写：
     - 场景（文案点名地点 / 室内外规则）
     - 布布在「够」的动作
     - 一二在「挡」的动作
     - 暖光打在谁身上
     - 道具（越重情绪越少）
     - 文字规则（只有载体才写字）
   - 角色外形必须用 `cast.json` 的原句；不要写角色名代替描述

4. **生图**
   - 16:9，Flow 队列 `flow_batch.mjs`
   - 先跑 3 张（开场 / 中段 / 结尾）确认方向，再批量
   - 每张检查：两只各一次、全身、无笑、无符号、暗蓝+暖黄、右下角干净

5. **预检 / 渲染 / 后检**
   - 页面图检查尺寸和文字
   - 渲染 `--skip-subs`，只出无字幕
   - 后检：尺寸/帧率/帧数/音轨/黑帧/响度/运动/手机图

6. **交付**
   - `E:\video-factory\<片号>\out\<片名>-无字幕.mp4`
   - 附 `qa/report.md`、联系表、手机图、`review.html`

## 硬规则

- 两只角色都**不要笑**，不画 w 形嘴、弯眼、露齿
- 情绪只靠眉毛、瞳孔、肩线、头颈、手、脚；不用问号/汗滴/闪光
- 除文案点名的文字载体外，整张图 0 文字
- 有文字：≤6 字/处、≤2 处、横排左起、无标点、一个载体
- 不要三视图、并排设定图、分格漫画
- 暖光有方向；暗蓝为主
- 右下角保留一小块干净深色地面，不放道具
