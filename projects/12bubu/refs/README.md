## 说明

- 1布布脸部纯白，**不要黑眼圈**；黑耳朵、黑领结、黑小脚是识别点。
- 2布布是棕色男熊，**不要黑眼圈、不要领结**，比1布布略大。
- 便签文字横排左起、水平正向，不旋转。
- 灯具/桌椅/道具靠左或中部，右下角 15% 空地面。
