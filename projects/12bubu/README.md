# 12布布 · 新角色项目

> 2026-11-17 重置：旧 `1bubu` / `2bubu` 项目停用，不再作为新片角色。
> 新项目 slug：`12bubu`；显示名：**12布布**。
> 角色：**一二（白色熊猫）** + **布布（浅焦糖小熊）**。

## 一、角色

| 角色 | 外形 | 关系位置 | 情绪方向 |
|---|---|---|---|
| **一二** | 白色圆润熊猫，黑色耳朵与眼圈，脸颊粉色腮红，颈间深棕色小领结 | 被挽回的一方 | **挡**：重心后撤、靠着或坐实、抱臂抱杯、手护住自己、只用眼角瞟、肩膀收着、耳朵下垂，情绪内收 |
| **布布** | 浅焦糖棕色小熊，圆耳，杏黄色腮红，身后一颗小圆尾巴 | 主动挽回的一方 | **够**：重心前压、身体倾向对方、伸手或递东西、视线追着对方、耳朵竖起、尾巴微翘，情绪外放 |

两只角色外形必须一致，**各只出现一次、全身入镜**。不要三视图、不要并排设定图、不要分格漫画。

## 二、风格

- 16:9 横向极简 Q 版扁平插画
- 干净深棕色轮廓线，平涂色块
- **无渐变、无阴影、无纹理**
- 整体**暗蓝色调**为主，只用少量**暖黄光**点缀
- 光要有方向：暖光打在谁身上，就说明谁在被挽留
- 右下角保留一小块干净的深色地面，不摆任何道具

## 三、情绪规则

- 布布永远在「够」，一二永远在「挡」；两者的力要能看出对抗
- 情绪只靠：眉毛高低、瞳孔朝向、肩线、头颈角度、手的开合、脚的朝向
- **不要**用头顶问号、汗滴、闪光、爱心、音符这类符号代替情绪
- 两只角色都**不要笑**：嘴角不上扬、不画 w 形嘴、眼睛不弯成弧线、不露齿

## 四、文字规则

只有当文案本身提到**消息、回复、评论、点赞、歌词、便签、卡片、牌子、招牌、写着**时，才在对应载体上出现文字；否则整张图**不出现任何文字**。

有文字时：

- 一处不超过 **6 个字**，整张不超过 **2 处**
- 内容直接从本段文案里摘最关键的词，不自己造长句、不写完整句子
- 能换成阿拉伯数字就换（编号、数量、时间）
- 全部**横排左起**，不要竖排
- 标准简体中文、无衬线黑体；横平竖直、字重均匀、字形正确无缺笔
- 不加任何标点符号；不要涂鸦字、伪汉字
- 字号小而清晰，不压在角色的脸和手上，不落在画面中下部
- 全图只允许**一个文字载体**；除它之外所有平面物体——广告牌、招牌、包装、书封、白板、卡片、路牌、灯箱、屏幕——一律纯色空白块，不写任何字、任何符号、任何 logo

## 五、场景与道具

**场景**：

- 文案点名了地点，就照它
- 没明说时：
  - 独处、居家、私人情绪、深夜手机/床/书桌 → **室内**
  - 通勤、公共场合、社交、被看见、过渡与等待 → **室外**

**道具**：

- 铺满但整齐，不要堆得杂乱
- 情绪越重的那张，道具反而要少；留白本身就是孤独
- 所有器物只用几何图形表现，不带文字
