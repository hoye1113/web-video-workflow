### 情绪低谷的具体做法（给 P2 用）

```
允许：  整体降明度、暖色转冷、加暗角、压高光、把光从"窗口侧"改成"局部单光源"
        表情在同一角色设定内变（低头 / 垂眼 / 抿嘴 / 背对镜头）
不允许：换外套颜色、换下装、摘掉头顶嫩芽、改发型
判据：  和"日间版"并排看，是"同一个人的不同处境"，不是"另一个角色的另一套衣服"
```

## 挂参考图的优先级

| 场景 | 用哪张 |

| 要角度一致 | 补 `*-side` |

**生成后自检**：跨页量**发色 / 服装主色 / 嫩芽位置**，判据「三个不同处境图 = 同一个人」。

## 遗留项

1. **`female-side.png` 的下装是青绿长裙**（与正面的白裤不一致）——
   挂参考图时避开它的下装，或后续用 Flow 重生成一张"侧面 + 白裤"
2. **两张 `*-variant.png` 都换了青绿外套** —— 已定**不当设定**（保留仅作"情绪参考"）
3. 女角色连帽衫是**接近背景的米白**（实测该区非背景色只占 1.9%）——
   一致性检查时要**容差放宽**，否则会把正常着装误判为"不一致"
