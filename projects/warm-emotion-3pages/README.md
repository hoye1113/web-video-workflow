# P2-d 总验收 · 三页对比（05 / 15 / 18）

用 `warm-emotion` 风格包**重做原片的 05 / 15 / 18 三页**，与旧版并排比对。

## 这是什么

| | |
|---|---|
| 目的 | 验证「处境图 + scene 组件 + 暖纸本风格」能不能替代旧版的"图表/大字"做法 |
| 来源 | 旁白沿用原片分镜（`projects/marriage_full/project.json`），略作精简 |
| 配图 | Flow 新生成的处境图（`projects/scene-library/`），1376×768 |
| 风格 | `packages/engine/styles/warm-emotion/`（GRAMMAR + 色板 + 9 个组件）|

## 三页的做法

| 页 | 处境图 | 一次有重量的动作 | 屏上字 |
|---|---|---|---|
| 05 妻子提离婚当晚 | `p05-kneel.png` 跪着、手撑地、面前一页白纸 | 镜头**推向那页协议**（停—推—停）| `离婚协议`（标签）|
| 15 白天正常晚上装没事 | `p15-night-door.png` 夜里在门口挂外套 | 镜头**慢慢推近门口** | 无 |
| 18 一边要家庭一边要刺激 | `p18-two-doors.png` 走廊两扇门（左暖右冷）| 两束光**先后亮起**（暖→冷）| `家里` / `外面` |

**三页都遵守 GRAMMAR**：一页一次有重量的动作、屏上字只做标签、下方 20% 留白（字幕带）、不画图表不画箭头。

## 跑法

```bash
cd projects/warm-emotion-3pages
node <engine>/tools/lint.mjs                    # lint: OK
node <engine>/tools/snap.mjs --sheet p2d 1.2 5.4 9 10.6 12.6 16.8 20.4 22 23.9 28.1 31.7 33.3
node <engine>/tools/render.mjs                  # → out/*.mp4
```

## 与旧版的差别

| | 旧版 | 新版 |
|---|---|---|
| 05 | 写实向插画（橙衣男子伏在文件上）| 同一个角色体系（小树）、暖纸本、有标签 |
| 15 | 几乎全黑的高对比图 | 夜里门口一盏暖光，看得清"在挂外套"这个动作 |
| 18 | **纯矢量：8 个方块的网格**（左红=家庭/右青=刺激）+ 中缝颤线 | **走廊两扇门的处境图**：左门暖、右门冷，人站在中间 |

第 18 页是这次对比最直观的一处：旧版**本身就是一张图表**，新版是**一个处境**。
