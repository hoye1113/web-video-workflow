规则（来自 `docs/新题材开工手册.md` 与 `projects/character-assets/character-cards.md`）：

① 主体是**处境**：谁 + 在哪 + 在做什么 + 光从哪来；不是图表、不是文字；
② 一页**一次有重量的动作**（停 → 那一下 → 停），其余停着；
③ 屏上字只做**标签**（≤8 字），画面下方 18% 永远留空（字幕带）；
④ **角色不写进提示词** —— 形象只靠挂 chip（小树=男 / 小芽=女），提示词里只写"一个男孩/一个女孩"；
⑤ **每张图都要量 `sprout_px`**，低于 ~50 不合格（头顶嫩芽 `#DEF0A8` 必须在）；
⑥ 生图**串行**，失败不连坐，断点续跑（已存在的文件跳过）。

## 施工顺序（表定了之后）

```
1. 新生成 26 张（挂 chip → 量一致性 → 不合格重画）
2. 逐页回填 page-spec.json 的 asset → python tools/make_pages.py --project infidelity-1021
3. edge-tts 配音 + 字幕（python tools/make_voice.py → script.mjs）
4. 整片渲染 → 抽帧验收（tools/qc_snap.py + tools/accept_emotion.py）
```
