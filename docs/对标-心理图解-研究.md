这也是它比真人出镜更适合流水线的原因：不需要生图、不需要 TTS、不需要对口型。

## 1. 内容骨架

参考片是标准的“问题 → 误区 → 原理 → 方法 → 收束”：

| 段落 | 大概时间 | 作用 |
|---|---|---|
| 钩子 | 0:00–0:20 | 用一个具体场景制造“我也这样”的代入：低头认错，却被拉黑 |
| 四个雷区 | 0:20–1:40 | 逐条否定错误做法：模板化道歉 / 情绪化求和 / 物质替代沟通 / 逼她立刻表态 |
| 核心原则 | 1:40–2:00 | 给出一句能记住的总纲：先留白，再谈对错，最后商量相处 |
| 四步方法 | 2:00–3:40 | 每一步一个动作 + 一句可照做的话 |
| 收尾 | 3:40–4:01 | 回扣标题，给情绪落点 |

**可复用的点：**

- 一页只讲一个观点，标题就是论点；
- 先列“不要做什么”，再给“怎么做”，观众更容易看完；
- 每一步都有“具体话术”，不是空道理；
- 结尾只回扣一次标题，不重复全片。

## 2. 视觉语法

### 底色与颜色

- 近黑底：`#0B0D10` / `#11151A`
- 主色：青 `#35E0D0`，用于“正确/冷静/主线”
- 强调：橙 `#FFA23A`，用于“情绪/提醒/重点”
- 警告：红 `#FF5A6A`，只用于“雷区/错误”
- 文字：白 `#F2F4F5`，次要信息灰 `#8A939B`

### 字体与排版

- 粗黑体做大标题，字号约 64–96px；
- 屏上正文 32–44px，单行不超过 14 字；
- 左上角固定“章节号 + 章节名”，例如 `04 两个雷区`；
- 底部固定字幕带，字号约 40–52px，关键词用青色或橙色；
- 画面四周留 80–120px 安全边距，底部再多留 180px 给平台 UI。

### 组件库

参考片真正反复用的，不是“插画”，而是这些信息图组件：

| 组件 | 用途 |
|---|---|
| `chat` | 微信聊天框、已送达、转账、拉黑 |
| `warning-row` | 四个雷区的警示三角 / 红卡 |
| `balance` | 天平：物质 vs 沟通 |
| `step-card` | 第 1 步 / 第 2 步的编号卡 |
| `timeline` | 冷静期、三天、半天一天 |
| `avatar-pair` | 两个圆点代表男女，靠近/远离/隔墙 |
| `checklist` | “我们的小约定”两条具体做法 |
| `quote` | 关键话术卡 |
| `end-card` | 结尾标题 + 回扣 |

### 运动

- 不做镜头运动，全部是 2D 元素动效；
- 文字：淡入 + 上移 20–40px，0.3–0.5 秒；
- 卡片：缩放 0.96 → 1，0.3 秒；
- 线条/箭头：描边生长，0.4–0.6 秒；
- 聊天框：逐条弹出，每条间隔 0.4–0.8 秒；
- 重点词：颜色切换或下划线，不做花哨粒子。

### 声音

- BGM 为主，音量约 -18 到 -16 LUFS；
- 转场加轻点击 / whoosh，不抢画面；
- 如果加口播，BGM 自动 duck 到 -24 LUFS 左右。

## 3. 制作流程（从选题到成片）

```
选题
 → 五段脚本（钩子/误区/原则/方法/收尾）
 → 页表（每页：时间、旁白、屏上字、组件、动效）
 → 页面代码（组件拼装）
 → 逐页渲染
 → BGM/音效
 → QA
 → 16:9 母版（可选 9:16 重排）
```

### 3.1 先定页数

- 30 秒：6–8 页
- 60 秒：12–16 页
- 3–4 分钟：24–32 页

一页 3–10 秒，按信息量定，不按时间硬切。

### 3.2 写页表，不写“分镜”

每页只填五样：

1. 这一页的论点（一句话）
2. 旁白/音频对应的句子
3. 屏上字（≤14 字/行，最多 2 行）
4. 用哪个组件
5. 元素出现顺序（先标题、再图、再重点词）

### 3.3 音频优先模式（后续接你的音频）

如果先有音频，流程反过来：

1. `tools/transcribe.py` 转写，拿到每段起止时间；
2. 按句子/语义切页，**不切在句子中间**；
3. 一页 3–10 秒；音频太长就加页，不加速；
4. 每页的第一句话和最后一句话必须和画面首帧/尾帧对得上；
5. 生成 `script-source.json` 的 `cues`，再用页面代码对齐。

关键规则：

- 页面切换点落在句号/问号/停顿处；
- 页内重点词出现时间 = 对应词在音频里的时间；
- 字幕和音频误差不超过 0.2 秒；
- 音频有口播时，屏上字只做关键词，不整句重复。

## 6. 验收标准

- 1920×1080，30fps，30 秒 ±1 秒；
- 手机小屏 1 米内能读清，单行 ≤14 字；
- 每 3–5 秒有一次画面变化；
- 关掉声音，信息不丢；
- 没有文字溢出、没有关键内容被平台 UI 挡住；
- 事实可追溯，不抄参考文案；
- 单页重渲 <30 秒，整片渲染 <5 分钟。
