# 项目代号 · P1 / P2 / P3

> 以后你说「用 P1 / P2 / P3」，就按这张表执行。
> 代号是**出片方案**（版式 + 风格 + 角色），不是单个片子。

## P1 · 原版留白（暖纸）

| 项 | 值 |
|---|---|
| 版式 | 全部 `card`：小图 + 四周留白，画面下方 20% 留空 |
| 风格 | 暖色纸本插画，平涂 + 细铅笔线 |
| 角色 | 小树 / 小芽（挂 chip） |
| 出图 | `make_pages` 的 P1；`decide_layout --mode p1` 把 layout 全设成 card |
| 适用 | 情感片、口播片，稳、干净 |

## P2 · 铺满 + 情绪特写（暖纸）

| 项 | 值 |
|---|---|
| 版式 | **70% 处境页铺满**（full）+ **30% 情绪特写**（close，干净纸底），自动分配 |
| 风格 | 暖色纸本插画，平涂 + 细铅笔线 |
| 角色 | 小树 / 小芽 |
| 出图 | `python tools/decide_layout.py <片> --mode p2` |
| 适用 | 想要更有电影感、画面更满的片 |

## P3 · 布布明亮版（新）

| 项 | 值 |
|---|---|
| 版式 | 沿用 P2 的 70/30（可切 P1） |
| 风格 | **治愈 Q 版扁平 · 明亮活泼**（`BUBU_STYLE` / `BUBU_TAIL`） |
| 角色 | **1bubu**（杏棕小熊）/ **2bubu**（暖白小熊），同框写 `1bubu+2bubu` |
| 色板 | 明亮杏棕 / 焦糖奶油；暖白 + 浅奶茶棕；嫩黄 / 樱花粉腮红 |
| 定稿图 | `projects/character-assets/{1,2}bubu-sheet-bright.png` |
| 角色卡 | `projects/character-assets/bubu-cards.md` |
| 自动生效 | 队列 cast 含 `bubu` → `full_prompt()` 自动套 `BUBU_STYLE`（不用手写提示词） |
| 适用 | 亲子 / 治愈 / 轻喜剧，想要明亮可爱 |

---

## 怎么"调用"

- 出片时告诉我 **「用 P3，音频在 xxx」** 即可，我按上表走（P3 = 明亮扁平 + 1bubu/2bubu + 70/30）
- 只要 P1/P2 的**版式**、不要布布角色：说「P2 + 小树小芽」
- 只要布布的**风格**、不要 70/30：说「P3 + P1 版式」

## 一句话对照

| 代号 | 版式 | 风格 | 角色 |
|---|---|---|---|
| P1 | card 留白 | 暖纸 | 小树 / 小芽 |
| P2 | 70/30 铺满+特写 | 暖纸 | 小树 / 小芽 |
| **P3** | 70/30（可改） | **明亮扁平** | **1bubu / 2bubu** |
