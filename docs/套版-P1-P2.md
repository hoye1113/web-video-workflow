# 套版 P1 / P2

> 两套版式，按需求选。不是两个独立工程，是同一个工程里的 `layout_mode`。
> 工作台首页有“套版”下拉；CLI 用 `tools/decide_layout.py`。

## 两套是什么

| | P1 · 原版留白 | P2 · 70/30 混合 |
|---|---|---|
| 图片 | 小图 + 四周留白，不铺满 | 70% 处境页全铺满 + 背景元素；30% 情绪特写干净背景 |
| 适合 | 安静、克制、绘本感；单对象/特写 | 情感口播、需要环境交代、16:9 成片 |
| 字幕带 | 图本身留白 | 底部 18% 纸色渐变 |
| 提示词 | `CARD_TAIL` | `TAIL`（full）/ `CLOSE_TAIL`（close） |

## P2 怎么判断 70 / 30

先按内容打分，再用 7:3 配额校准，不是机械按页数切。

**倾向 full（处境页）**：

- 交代环境、动作、多个物件、转场
- 关键词：房间、窗、桌、门、柜、书架、绿植、窗帘、站、坐、走、推、拿、光、夜、雨……
- 首屏、钩子、案例、正文

**倾向 close（情绪特写）**：

- 情绪落点、回忆、内心动作、单一物件
- 关键词：才知道、原来、终于、沉默、眼泪、哭、笑、心疼、后悔、害怕、孤独、累、释然、舍不得、等不了、闭眼、低头、看着、想起、手、脸、眼睛、嘴角……
- 转折、落点、结论、最后一页

**配额**：

- 目标 close = `round(页数 × 30%)`，至少 1 页（≥2 页时），最多留 1 页 full
- 4 页 → 3 full + 1 close（75/25，最接近 70/30）
- 60 页 → 约 42 full + 18 close

**手工覆盖**：

在 `page-spec.json` 的某页写：

```json
{ "layout": "close", "layout_manual": true }
```

`decide_layout.py` 不会覆盖这一页。

## 用法

```powershell
# 看判定结果，不写文件
python tools/decide_layout.py demo-candy-1029 --mode p2 --check

# 写回 page-spec.json，并更新还没开始画的队列任务
python tools/decide_layout.py demo-candy-1029 --mode p2

# P1：全部 card
python tools/decide_layout.py demo-candy-1029 --mode p1
```

工作台：首页“套版”选 P1 / P2 → 写进 `brief.json` 的 `layout_mode` → 分镜点头后 `build_queue` 按模式给每页写 `layout` → `gen_worker` 用对应提示词。

## 代码位置

| 文件 | 作用 |
|---|---|
| `tools/decide_layout.py` | 打分、7:3 配额、写 `layout` |
| `tools/gen_scenes.py` | `CARD_TAIL` / `TAIL` / `CLOSE_TAIL`，`full_prompt(scene, layout)` |
| `tools/gen_worker.py` | 按任务的 `layout` 选提示词 |
| `tools/pipeline.py` | `queue_add(..., layout=...)` |
| `apps/intern/server.py` | 表单 `layout_mode`、`build_queue` 自动分配 |
| `apps/intern/ui.html` | 首页“套版”下拉 |
| `warm-emotion/style.css` | `#frame::after` 底部字幕带渐变 |
