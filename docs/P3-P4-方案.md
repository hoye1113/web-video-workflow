### 步骤 2 · 补生成缺的处境图

- 用 Flow（本机已验证可行）：`Add ingredients → Characters → 选 小芽/小树 → Add to prompt → 生成`
- 一次一张，站内抓回（`flow.google.com/asb/...` 是 WebP，落盘转 PNG）
- 每张生成后**量一致性**（发色 / 服装主色 / 嫩芽），不合格就重画（比稿留好的那版）
- 目标：图库能覆盖的**不重复生成**（16 张通用处境先复用）

### 步骤 3 · 逐页写场景代码

照 `projects/warm-emotion-3pages/pages/p05.js` 的写法（`P.scene(assets/xx.png, {...})`）：
- 一页**一次有重量的动作**（推近/拉远/明暗/一个局部）
- 屏上字只做标签；下方 20% 空着
- 每页写完跑 `lint.mjs` + `snap.mjs` 看关键帧
