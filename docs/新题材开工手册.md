## 0. 先定两个数（**别跳过这步**）

第一部没先定时长，写完 9 分 52 秒，用户嫌长。实测换算：

```
cue 字数 ≈ 4.2 × 秒数      （1915 字 → 592 秒 → 194 字/分钟）
```

| 想要的片长 | 台词字数 | 页数（每页 10–15 秒） |
|---|---|---|
| 5 分钟 | ~1000 字 | 20–25 页 |
| **6 分钟** | **~1200 字** | 24–30 页 |
| 8 分钟 | ~1550 字 | 30–40 页 |

**先把目标片长说定，再写字。**

## 1. 写台词（唯一必须人写的东西）

文件：`projects/<新片>/script-source.json`

- **一条 cue ≈ 12 字以内**，且**第 12 个字之前必须有一个标点**
  （否则字幕切行会切开词：实测"支付工具"会被切成"支/付工具"）
- 一页 4–8 条 → 一页 10–15 秒；页与页之间留 0.3–0.8 秒空档
- 骨架（好用的那个）：**钩子 → 案例 ×2-3 → 反直觉结论 → 真相拆解 → 行动与落点**
- 写完审一遍：

```bash
python tools/check_cues.py        # 目标：0 条硬切
```

## 2. 出图（先复用图库，缺的才生成）

```bash
python tools/measure_lib.py         # 看图库里有什么（20 张）
python tools/gen_scenes.py --list   # 看生成清单
python tools/gen_scenes.py 03 11    # 只做指定页（改 gen_scenes.py 里 ITEMS 的 scene 描述）
```

- 提示词只写**处境**："谁 + 在哪 + 在做什么 + 光从哪来"
- **角色不写进提示词** —— 靠挂 chip（`小树`=男 / `小芽`=女），写进去形象就跑了
- 生成完**一定要看图**（抽帧或直接看）；不对的挪到 `experiments/rejects/` 再重画
- 每张约 60–100 秒；17 张约 25 分钟

## 3. 排页（改**工程自己的页表**）

每个工程有一份自己的页表：`projects/<新片>/page-spec.json`
（照 `projects/emotion-full/page-spec.json` 那份复制/改；**工具本身不用动**）

每页 = **图 / 主题 / 机位 / 明暗 / 光 / 屏上字**

```bash
python tools/make_pages.py --project <新片>     # → projects/<新片>/pages/pNN.js
python tools/make_pages.py --export             # 从代码里那份表导回 json（一般不用）
```

- 机位四选：`push40`（40% 处推近）/ `push55` / `pull`（拉开）/ `tight55`（主体太小就收紧）
- 一页**一次有重量的动作**，其余停着；不要整页匀速慢推
- 屏上字只做标签（≤ 8 字）；**画面下方 18% 什么都不放**（字幕带）
- 光要落在主体/物件上，**不要飘在空角落**（会是一团圆圈）
- 夜景图记得 `theme="night"`（否则深色标签在暗底上看不见）

## 4. 出片（四条命令）

```bash
python tools/make_script_js.py --from-source        # → script.js
python tools/make_voice.py                          # → audio/*.wav + voice.js（约 10 分钟）
cd projects/<新片>
node <engine>/tools/script.mjs                      # → out/口播脚本.md + out/字幕.srt
node <engine>/tools/render.mjs                      # → out/*.mp4（分段并行，约 20 分钟）
```

新工程第一次要先跟引擎接上（建 junction）：

```bash
node -e "import('./packages/engine/tools/project.mjs').then(m=>m.linkProject('D:/WorkSpace/video-factory/projects/<新片>'))"
```

## 5. 验收（看两张表 + 一条命令）

```bash
python tools/qc_snap.py                  # 26 页 × 3 帧对照表 → out/snap/qc1.jpg qc2.jpg
```

## 想更紧凑，调这三个参数

| 参数 | 在哪 | 现值 | 说明 |
|---|---|---|---|
| `RATE`（语速） | `tools/make_voice.py` | **-4%** | 负得越多越慢（第一部用 -8% 太长） |
| `TAIL`（停顿） | 同上 | 句号 0.35 / 逗号 0.20 | 停顿补在音频末尾；全片停顿总量靠它 |
| `FRAMETELL_SUB_MAX` | 环境变量 | 12 | 字幕每行最多几个字 |
