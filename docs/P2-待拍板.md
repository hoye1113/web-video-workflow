## B-2 · 验收判据（拟了 5 条，可改）

| # | 判据 | 怎么看 |
|---|---|---|
| **1** | **认得出是同一对角色** | 3 页与定妆图并排，发色 / 服装 / **嫩芽**一眼对上 |
| **2** | **不违和** | 角色与背景像同一个世界（同一支笔、同一套光）|
| **3** | **有"处境感"** | 一眼看懂"这人处在什么情境里"，不是"标题 + 图标" |
| **4** | **没有图表味** | 没有箭头 / 圆圈 / 流程图 / "标题+三卡" |
| **5** | **愿意发** | 愿意拿它去发 —— 最硬的一条 |

**通过线**：**5 条里至少 4 条"是"，且第 1、5 条必须"是"。**

- 第 1 条（识别度）与第 5 条（可用性）是不可退让的底线
- 其余 3 条是质量问题，允许一次迭代

**不通过时的退路**（方案 §5 已定）：
> 退回「同场景复用同一张图 + 少量人绘」—— 不硬追"每页都生成新处境图"，
> 改成在少数几张图上做运镜与明暗。
