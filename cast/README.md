## 女主

**一句话**：浅栗灰粉短发、米白超大号卫衣、头顶冒一片两叶嫩芽的 Q 版女孩。

- **比例**：Q 版约 3 头身（头大、四肢短）
- **发**：浅栗灰粉（灰多粉少），齐肩、发尾微内扣；刘海厚、盖额
- **记忆点**：**头顶一片两叶嫩芽**（浅黄绿）—— 两个人都有，是一眼认出他们的标志
- **眼**：浅绿（橄榄绿），大眼；默认**无表情/放空**（不是笑）
- **服装 A**（正式图）：米白色超大号连帽卫衣，袖子长到把手藏进去，下摆盖过胯；光腿；深棕小短靴
- **服装 B**（坐姿）：浅青绿外套 + 同色围巾 + 浅绿堆堆袜 + 浅棕鞋
- **表情库（现有）**：平静/放空、困惑（微微仰头）

## 还缺的视图（用 Flow 挂参考图生成 → 给你审）

现有定妆图覆盖了：正面 / 侧面 / 3-4 面 / 大头 / 坐姿。缺的是**情感片真正用得多的那些角度**：

| 缺 | 为什么重要 | 数量 |
|---|---|---|
| **背面** | 背影是情感片的主力镜头（背对站着/走开/坐床边） | 每人 ×1 |
| **3/4 背侧** | 转身、走向门口的过渡姿态 | 每人 ×1 |
| **表情头（近景）** | 情绪靠脸：**忍 / 难过 / 哭 / 疲惫 / 释然 / 强笑 / 惊讶 / 平静** | 每人 ×8 |
| **动作组** | 站 / 坐沙发 / 蹲 / 躺 / 扶额 / 背对 | 每人 ×6 |
| **两人同框** | 关系片必然同框；**画在一起**才能锁相对身高和配色关系 | ×2 |

## 生成时怎么用（要遵守的三条）

1. **必须挂参考图**：提示词 = `角色卡文字 + 场景描述`，并挂上 `girl.jpg` / `boy.jpg`。
   不挂参考图生成的人，一律不算数。
2. **每人一个唯一识别色**：女 = 米白 + 浅栗 + 嫩绿；男 = 灰蓝 + 深棕。
   同框时在提示词里分别点名，避免模型把两人画混（实测最常见的失败是**互换衣服颜色**）。
3. **Q 版比例要写死**：提示词里带 `chibi, 3-head-tall proportions, big head`，
   否则模型会往写实比例拉。跑偏了靠自动重画兜（量嫩芽 / 发色 / 服装主色）。

## 一致性怎么判（自动，不靠人一张张看）

生成后自动量三样，低于阈值就带着修正重画（比稿留好的那版）：

1. **头顶嫩芽**：头部上方 15% 区域内，有没有一小块黄绿（`#C3D98A` 附近）
2. **发色**：头部区域的主色，与定妆卡的浅栗粉 / 灰蓝比色相
3. **服装主色**：画面主色簇是否落在该角色的识别色里
